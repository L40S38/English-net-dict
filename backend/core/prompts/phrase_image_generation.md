# Phrase Image Generation Prompt Template

熟語「{phrase_text}」の意味の成り立ちを、構成する単語それぞれの意味から説明する教育用インフォグラフィックを作成してください。

【重要な制約】
- すべてのテキスト・図・ボックスを画像の端から十分な余白（上下左右）を取って配置し、絶対にはみ出さないこと
- 熟語が指す状況をそのまま写実的に描いた1枚絵にしないこと（NG例：「tap water」で蛇口から水が出ている情景だけを画面いっぱいに描く、など）
- 必ず「構成単語ごとの分解」→「意味が組み合わさる過程」→「熟語全体の意味」という3段階の図解にすること
- 画像内にロゴ・透かし・出典表記・ブランドマーク・架空のウェブサイト名などを一切含めないこと

【構成】
- 縦長構図（1024×1536px）
- 上部に構成単語をそれぞれ分解して表示し、単語ごとに簡単なアイコン・イメージと意味を添える
- 中央で各構成単語のイメージが矢印で合流し、熟語全体のコアイメージへとつながる図
- 下部に熟語全体の意味（日本語）と英語例文を1つ

【デザイン】
- やわらかい教育系デザイン（単語の語源解説図と統一感のあるスタイル）
- 背景は淡色
- 矢印で「構成語→熟語の意味形成」の流れを明確に
- 構成単語ごとに色分け
- 日本語説明＋英語例文付き、文字は見やすく

【内容要件】
1. 構成単語（それぞれの意味と簡単なイメージ）
2. 構成単語が組み合わさってできるコアイメージ（1フレーズ）
3. 熟語全体の意味（日本語）
4. 熟語を使った短い英語例文を1つ

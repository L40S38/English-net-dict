# design_doc/ について

本ディレクトリは **English-net-dict**（個人用英単語・語源辞書アプリ）の仕様書一式である。現状のコードベースを対象とした **as-built（現状記述）仕様書** であり、将来の機能追加を提案するものではない。読み手は人間の開発者と、今後このリポジトリを扱うAIエージェントの両方を想定している。

## `docs/` との関係

リポジトリ直下には既存の `docs/`（`architecture.md` / `database.md` / `review.md`）が存在するが、これらは2026年8月時点でかなり古くなっている。具体的には、旧 `backend/app/` ディレクトリ構成（現在は `backend/server` と `backend/core` に再編済み）を前提に書かれており、リスニング練習機能（8テーブル・18エンドポイント・専用フロントエンド一式）が丸ごと欠落しているほか、熟語（phrase）の定義・画像テーブルや活用形（inflection/lemma）統合機能も反映されていない。

**`docs/` の内容はそのまま残すが、現状の仕様としては本 `design_doc/` を参照すること。** `docs/` 側のファイルには手を加えていない。

## 本ドキュメント群の構成方針

ディレクトリは3つの役割に分かれている。

```
design_doc/
  README.md          ← このファイル
  00_overview.md      ← 全体の30秒オリエンテーション
  backend/            ← バックエンドの一次情報源（構造的事実）
  frontend/           ← フロントエンドの一次情報源（構造的事実）
  features/           ← 機能ごとの「動作の物語」（横断的な流れ）
```

- **`backend/` と `frontend/` が一次情報源（root）である。** テーブル定義、エンドポイントのRequest/Response、コンポーネント一覧、サービス一覧といった網羅的な事実はここにのみ書かれている。
- **`features/` は機能ごとの動作の物語に徹する。** データモデルやエンドポイントの詳細は書かず、「詳細は `backend/02_database.md` の◯◯クラスタを参照」のようにリンクした上で、その機能に固有のフロー・判断ロジック・複数コンポーネントの繋がり方（シーケンス図・フローチャート等）のみを記述する。
- 複数の機能にまたがる仕組み（チャット＆ツール、画像生成、活用形統合など）は、関連する全ての機能ファイルに重複して書かず、専用の機能ファイルに一度だけ書き、他の機能ファイルからはそこへリンクする。

この方針により、同じ内容が複数ファイルに重複して書かれ、更新のたびに記述がズレていく事態を防ぐ。**あるファイルを更新した際、他のファイルに同じ情報のコピーが無いか常に意識すること。**

## 表記規則

- 本文は日本語で記述する。ただし、コード識別子・ファイルパス・エンドポイントパス・テーブル/カラム名・環境変数名・LLMモデルIDなどは英語のまま表記する（翻訳しない）。
- Mermaid図のノードIDとラベルは、日本語や記号（`/`、スペースなど）を避け、英数字とアンダースコアのみで構成する（例：`Frontend_React_Vite`）。これは既存 `docs/architecture.md` の慣習を踏襲したもので、Mermaidパーサーが日本語や記号を含むラベルで崩れることがあるための回避策である。エッジラベルや周辺の説明文は日本語でよい。
- 現状を記述する際は常に「現在どうなっているか」を書き、移行中・レガシー・非推奨のものは婉曲的に隠さず明示する（例：`core/migrations/runtime_sqlite.py` は現在どこからも呼ばれていないデッドコードである、など）。

## 読む順番の目安

- **全体像をざっと掴みたい場合**：`00_overview.md` → `backend/01_architecture.md` → `frontend/01_architecture.md`
- **特定機能を理解したい場合**：`00_overview.md` の用語集を確認 → `features/` 配下の該当ファイルを読み、リンク先の `backend/`・`frontend/` を必要に応じて参照
- **特定のテーブル/エンドポイント/コンポーネントを調べたい場合**：`backend/02_database.md`・`backend/03_api.md`・`frontend/02_components.md` を直接引く
